    Readers¶

    A reader yields a file as Arrow record batches holding the model columns present in the file. Text formats yield raw strings, so the conversion policy sees exactly what the file contains. Typed formats yield their stored types. A reader decides nothing about missing values: an empty field is an empty string, and the null policy is applied afterwards.

    open_reader picks the reader from the file suffix: .parquet is read as Parquet, any other suffix as delimited text. load_file opens the reader with it, taking quote_mode and chunksize as arguments, and load_file(reader=...) passes a configured reader explicitly.

    Reader Input
    DelimitedTextReader Delimited text with a tab or comma delimiter and detected encoding
    ParquetReader Parquet files, in batches of chunksize rows

    DelimitedTextReader¶

    Reads raw strings in 4 MB blocks, so memory does not grow with the row count. Header names are lowercased and stripped of quotes, padding and a trailing _hash, and file columns that are not model columns are ignored with a warning. Parquet column names are normalised the same way.

    quote_mode selects how double quotes are read:

    Mode Behaviour
    csv Double quotes quote fields
    literal Double quotes are data
    by_delimiter (default) literal for tab-delimited files, csv otherwise

    Bases: FileReader

    A delimited text file read as raw strings in bounded blocks.

    Every value is kept as read, so an empty field is an empty string and nothing is null. Date columns are dictionary-encoded. Header names are normalised as described by normalise_headers. File columns that are not model columns are ignored.

    Detection¶

    The delimited reader detects the encoding with chardet (ASCII is normalised to UTF-8, and only a small prefix of the file is inspected), the delimiter from the first line (tabs win over commas when more frequent).

    Resolve a requested quote_mode to a concrete "csv" or "literal".

    Parameters:

    Name Type Description Default
    quote_mode str
